# 题目数量怎么选：统计功效与预算的权衡（2026-10-29）

## 一、先分清两个目标

| 目标 | 需要的量 | 说明 |
|---|---|---|
| **A. 估计"某版本通过率"** | 60–200 题 | 题越多，区间越窄 |
| **B. 比较两版本差异（A/B）** | 每组 83–330 题 | 要测出的差异越小，需要的题越多 |

**关键**：重复同一题只能降低"运行噪声"（我们实测同题会一过一败），**降低不了"题目异质性"**；要检测版本差异，必须靠**增加不同题目数量**。所以"题量优先，重复为辅"。

### 推荐：120 题 × 2 重复（¥12，约 13h）
- **题量**：从 519 可评测里**按仓库分层随机抽样 120 题**（含 HARD-51 高难度层，避免偏差）
- **重复 2 次**：抵消同题运行方差（实测同题可一过一败）
- **统计能力**：单次估计 ±9pp；可检测约 18pp 的版本差异
- **成本**：约 ¥12，预算内且留余量

## 五、必须诚实说明的边界

1. **我们实际的优化效应多是 5–10pp**（如 token 控制成功率持平、提示词规则 3/5 翻盘）。**¥50 预算测不出 10pp 以下的提升**——那是 300+ 题/组的量级。
2. 因此现实目标应是：**可靠检测 15–20pp 的效应**，或确认"大改动没有回退"。
3. 若一定要测小效应：分 3–4 次累计，或提高预算；单次 ¥50 做不到。
4. **报告必须按层分**：HARD-51（高难度，通过率低）与整体 519（通过率高）是不同分布，不能混算。

## 六、结论一句话

**别只加重复，要加题量。** 预算 ¥50 内最优是 **120–180 题 × 2 重复**（¥12–18，13–19h），能可靠检测 15–18pp 的差异；若要更小效应的结论，需提高预算或分批累积。
