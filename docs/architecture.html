二、单轮执行时序

1
用户输入 → InteractiveLoop（历史/补全）或 headless -p lib/runtime/interactive.py · cli/headless.py
2
SAIAgent.run / stream_run 开 turn：TurnState(NEXT_TURN)，进 tool_execution_session lib/agent.py
3
_prepare_messages：压缩检测 → 刷 system → 增量取本轮 HumanMessage（历史在 checkpointer 里）
4
AgentRunner.invoke/stream：create_agent 图执行，中断走 interrupt()→handler→Command(resume)
5
异常进 _classify_error 四档恢复：限流退避 / 输出超限续写 / 上下文超限强制压缩 / 致命错（≤3 次）
6
finish_turn：记记忆 + 会话 + 用量，TurnState(COMPLETED) 收尾

三、中间件洋葱（外层在前）

1 · SayaHookMiddleware
Pre/Post/ToolFailure 唯一发射方 · 同级中止检查
2 · SayaPermissionMiddleware
peek 判定 · deny 短路 · ask 走 interrupt，批准后 grant_once
3 · SayaSafetyMiddleware
critical 只否决不升级（用 tools/safety 严判据）
4 · SayaPromptMiddleware
wrap_model_call 注入本轮 system（dynamic_prompt，每轮一次）
ToolNode 执行工具函数

四、权限判定优先级（高→低，唯一出口 _decide）

0 地板危险工具 delete_file / git_push 的任何 allow 强制降 deny（通配/改字典/策略文件一视同仁）
1mode 规则中的 deny（plan/review 只读硬约束，不可绕开）
2session 授权（弹窗“始终允许”累加，切 mode 不清空）
3mode 规则中的 allow / ask
4user / project 策略文件（project 覆盖 user；显式 deny > commands > paths > tools 通配 > default）
5 默认built-in：只读 allow，写/Git 安全集 allow，危险 ask

五、工具延迟加载（启动只绑 34 个）

初始可见

文件读写改删、常用 Shell/Git、ToolSearch、invoke_tool、batch_execute
